# Cracker

치지직 라이브 녹화, 다시보기·클립 저장 앱입니다.

네이버 로그인 쿠키는 기기 로컬에만 저장되며, 외부로 전송되지 않습니다.

## 요구사항

Android 15 (API 35) 이상에서 동작하며, 백그라운드 다운로드 진행 상황을 표시하기 위해 알림 권한이 필요합니다.

## 주의사항

앱을 통해 저장한 영상의 저작권 및 치지직 이용약관 준수 책임은 사용자에게 있습니다.

## APK 빌드·배포

GitHub Actions는 `main` 푸시 또는 수동 실행 시 APK를 한 번 빌드합니다.
릴리스할 때는 앱 버전과 일치하는 태그(예: `v2.1.3`)를 만들고,
`git push --atomic origin main v2.1.3`처럼 커밋과 태그를 함께 푸시합니다.
해당 커밋에 버전 태그가 있으면 APK를 GitHub Release에 게시하고,
없으면 7일 보관하는 Actions 아티팩트로 올립니다.

태그만 나중에 푸시한 경우에는 그 태그를 대상으로 워크플로를 수동 실행합니다.
Gradle 빌드 결과 캐시는 GitHub에서만 활성화하며 `main` 빌드끼리 재사용합니다.
